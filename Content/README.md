# Content/ — Generated Content Repository

> **Purpose:** All articles, social media campaigns, newsletters, and case studies generated by the **TailorAI Content Creator Agent** are stored here.
> Organized chronologically and by content type.

---

## Directory Layout

```text
Content/
├── Articles/        # Long-form blog posts, SEO guides, thought pieces (.md)
├── Social/          # LinkedIn posts, X/Twitter threads, platform snippets (.md)
├── Newsletters/     # Email newsletter campaigns & broadcasts (.md)
└── Case_Studies/    # Customer success stories & implementation breakdowns (.md)
```

---

## File Naming Convention

Every generated file must follow this kebab-case naming standard:
`YYYY-MM-DD-[slug-title].md`

Examples:
- `Content/Articles/2026-10-21-why-cloud-compliance-fails.md`
- `Content/Social/2026-10-21-linkedin-cloud-security-mistakes.md`
- `Content/Social/2026-10-21-x-thread-cut-aws-bill.md`
- `Content/Newsletters/2026-10-21-issue-12-zero-trust-first-principles.md`

---

## Automated Logging
Whenever a new file is written to `Content/`:
1. The agent updates [`.tailorai/ACTIVE_TASKS.md`](file://.tailorai/ACTIVE_TASKS.md) to close the active task.
2. The agent appends a permanent record to the published inventory table in [`.tailorai/PROJECT_MAP.md`](file://.tailorai/PROJECT_MAP.md).
