# SEO_Optimization.md — Search Intent & On-Page Architecture

> **Skill Purpose:** Ensure every article achieves high search engine visibility, satisfies user intent, and earns organic backlinks.

---

## 1. Search Intent Classification

Before writing, identify the reader's core search intent:
1. **Informational:** *"What is CSPM?"* → Needs comprehensive explanation, diagrams, and definitions.
2. **Commercial / Investigational:** *"Best cloud compliance tools for Kubernetes"* → Needs objective comparison matrices, pros/cons, and pricing context.
3. **Transactional:** *"Hire DevSecOps consultant"* → Needs direct value proposition, client testimonials, and simple booking CTA.

---

## 2. On-Page SEO Checklist

- [ ] **H1 Tag:** Exactly one H1 containing primary keyword near the beginning.
- [ ] **URL Slug Friendly:** Suggest clean slug (e.g., `/cloud-compliance-guide/`).
- [ ] **Meta Description:** 140–160 chars with primary keyword, benefit, and curiosity hook.
- [ ] **Heading Hierarchy:** Sequential H2s and H3s without skipping levels.
- [ ] **Keyword Density:** Natural keyword integration (0.8%–1.5%), zero keyword stuffing.
- [ ] **Semantic LSI Terms:** Include 5–8 related domain terms naturally throughout body text.
- [ ] **Scannability:** Bullet lists, bolded concepts, and summary tables.
- [ ] **Featured Snippet Bait:** A concise 40–55 word direct answer definition right under an H2 question header.
