## How to Initialize or Re-configure
To configure this workspace for a new brand or client:
1. Open an AI Agent session (Antigravity, Cursor, Claude Code, or web dashboard).
2. Execute the protocol: `init-agent.md`.
3. Follow the 6 guided onboarding steps.
